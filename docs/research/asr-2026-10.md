# Offline CPU speech-to-text for a subtitle app: research (as of 2026-10-15)

## 0. Method and limits

- The Hugging Face Open ASR Leaderboard Space is JavaScript-rendered and could not be read directly ([leaderboard](https://huggingface.co/spaces/hf-audio/open_asr_leaderboard), [mirror](https://hf-audio-open-asr-leaderboard.hf.space/)). English rankings come from two third-party snapshots: [benchmarklist.com, updated 6 May 2026](https://benchmarklist.com/benchmarks/open_asr_leaderboard/) and [codesota.com, "Updated 2026"](https://www.codesota.com/browse/speech/speech-recognition/open-asr-leaderboard). The leaderboard's multilingual tab could not be read (unverified).
- Multilingual numbers come from model cards and the Open ASR paper ([arXiv 2510.06961 v3](https://arxiv.org/html/2510.06961v3), Tables 1, 3, 4). FLEURS averages from different cards use different subsets and normalisation, so they are not strictly comparable across models.
- No model below has a verified long-form WER on CPU, except the user's own measurements (Parakeet v2 long-form 2.2%, RTF 0.09 fp32; Whisper large-v3-turbo int8 long-form 5.3%, RTF 0.41, both on a Ryzen 1700X). These are taken from the task brief and were not re-checked.
- Cards describe RAM and speed mostly for GPU. Where CPU figures are missing, this is marked "CPU unverified".

## 2. Direct answer

**No model has been shown to beat "Parakeet v2 (English) + Parakeet v3 (24 European) + Whisper (rest)" for all languages on CPU.** The evidence points to a narrower upgrade, not a single model:

- **European leg:** Canary-1B v2 has a better published FLEURS-25 average (8.40%, [card](https://huggingface.co/nvidia/canary-1b-v2)) than Parakeet v3 (11.97%, [card](https://huggingface.co/nvidia/parakeet-tdt-0.6b-v3)) on the same 25 languages. The Open ASR paper's five-language numbers are roughly tied (4.99 vs 5.11 average, [arXiv](https://arxiv.org/html/2510.06961v3)). Canary v2 is a plausible replacement for Parakeet v3 if CPU speed is acceptable. This is unverified on CPU, and it is 1B parameters versus 0.6B.
- **English leg:** Parakeet v2 (6.05, [arXiv](https://arxiv.org/html/2510.06961v3)) is better than Canary-1B v2 (7.15, [benchmarklist](https://benchmarklist.com/benchmarks/open_asr_leaderboard/)) on the leaderboard. Better English scores (Granite 4.1 at 5.33, Canary-Qwen 2.5B at 5.63) have no verified CPU route. Canary-Qwen is also English-only and listed as GPU-optimised ([card](https://huggingface.co/nvidia/canary-qwen-2.5b)). Parakeet v2 stays the English choice.
- **Rest of the world:** Only Whisper (99 languages, MIT, timestamps, CPU runtimes verified) is a broad-coverage option with verified CPU runtimes. Qwen3-ASR-1.7B covers 52 languages with better English and Open ASR scores, but timestamps need an aligner for 11 languages and its CPU speed is unverified. Omnilingual covers far more languages, but its CPU path and timestamps are undocumented.

Recommended next step: benchmark Canary-1B v2 (GGUF via transcribe.cpp) against Parakeet v3 on the user's own European test files, with the same long-form protocol as the user's earlier measurements. Verify the Nemotron 3.5 licence text before considering it.

## 3. Excluded

Licence (not acceptable for a free distributed app, or unclear):
- **SenseVoice-Small**: FunASR Model License v1.1, not an OSI licence ([OpenASR](https://huggingface.co/OpenASR/sensevoice-small)). Also only 5 languages (ZH, Cantonese, EN, JA, KO), and "plain transcription" only, so no timestamps ([OpenASR](https://huggingface.co/OpenASR/sensevoice-small)).
- **Canary-Qwen 2.5B**: CC-BY-4.0, but English only, NeMo runtime, GPU-optimised ([card](https://huggingface.co/nvidia/canary-qwen-2.5b)). Excluded on CPU and language grounds.
- **Nemotron 3.5 ASR**: OpenMDW-1.1 licence, not checked against text. Kept as rank 5 only pending verification.

Excluded on size, CPU, or coverage:
- **Voxtral Mini 3B (2507)**: Apache-2.0, 8 languages, vLLM recommended, ~9.5 GB GPU RAM in bf16, no llama.cpp, timestamps not mentioned ([card](https://huggingface.co/mistralai/Voxtral-Mini-3B-2507)). Excluded.
- **Voxtral Mini 4B Realtime (2602)**: Apache-2.0, 13 languages, streaming, vLLM only, Open ASR 7.68, no timestamps mentioned ([card](https://huggingface.co/mistralai/Voxtral-Mini-4B-Realtime-2602)). Excluded. The "Transcribe 2.0 offline" FLEURS avg 5.90% has no verified weights ([card](https://huggingface.co/mistralai/Voxtral-Mini-4B-Realtime-2602)).
- **Phi-4-multimodal-instruct**: MIT, 8 ASR languages, 5.6B params, no timestamps mentioned, ONNX variant exists but RAM/CPU unverified ([card](https://huggingface.co/microsoft/Phi-4-multimodal-instruct)). Open ASR 6.02 ([benchmarklist](https://benchmarklist.com/benchmarks/open_asr_leaderboard/)). Excluded on size.
- **Kyutai STT 1B en_fr**: CC-BY-4.0, English and French only, no WER numbers on card, timestamps recoverable from token offsets ([card](https://huggingface.co/kyutai/stt-1b-en_fr)). Kyutai STT 2.6B (model name `stt-2.6b-en`, so English only per its name) appears at Open ASR 6.40 ([benchmarklist](https://benchmarklist.com/benchmarks/open_asr_leaderboard/)); its card was not read. Excluded.
- **FireRedASR2 (AED / LLM)**: Apache-2.0, Mandarin and Chinese dialects plus English, CER only, no timestamps mentioned ([card](https://huggingface.co/FireRedTeam/FireRedASR2-AED)). Excluded on coverage.
- **Dolphin (base/small)**: Apache-2.0, 40 Eastern languages and 22 Chinese dialects, no European languages, no timestamps mentioned, large models not public ([card](https://huggingface.co/DataoceanAI/dolphin-base)). Excluded.
- **Moonshine (tiny/base/streaming)**: MIT, Open ASR 9.99–12.65 for base/tiny, mainly English ([benchmarklist](https://benchmarklist.com/benchmarks/open_asr_leaderboard/)). Excluded on accuracy.
- **Granite Speech 3.3 8B**: Open ASR 5.74, too large for 8–16 GB CPU use ([benchmarklist](https://benchmarklist.com/benchmarks/open_asr_leaderboard/)). Excluded on size (unverified RAM).
- **Omnilingual LLM 7B**: 30 GiB download, ~17 GiB VRAM, RTF ~1x relative to itself on A100 ([card](https://huggingface.co/facebook/omniASR-LLM-7B)). Excluded on size.

## 4. Other notes

- Among the NeMo models, the sherpa-onnx docs list int8 exports with timestamps only for Parakeet TDT v2 and v3 ([sherpa](https://k2-fsa.github.io/sherpa/onnx/pretrained_models/offline-transducer/nemo-transducer-models.html)). Canary is not in that list. The sherpa-onnx index also links model pages for Whisper, Omnilingual, Qwen3-ASR, Cohere Transcribe, FireRedAsr, Dolphin and SenseVoice ([sherpa](https://k2-fsa.github.io/sherpa/onnx/index.html)). Those pages were not read, so their CPU and timestamp status is unverified.
- Handy (a free offline dictation app) is described as using transcribe.cpp in a search snippet ([search](https://betterstack.com/community/guides/ai/handy-offline/)); not verified against Handy's own source. Its current model list is unverified.
- The Parakeet CTC 0.6B GGUF shows Q4_K_M at 469 MB with WER 1.90% on LibriSpeech test-clean, which is a relevant quantisation data point for the Parakeet family ([GGUF card](https://huggingface.co/handy-computer/parakeet-ctc-0.6b-gguf)).
- Open ASR "RTFx" figures are GPU measurements from the leaderboard and are not usable for CPU planning.

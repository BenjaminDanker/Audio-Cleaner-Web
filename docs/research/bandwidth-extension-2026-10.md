# Speech bandwidth extension (BWE) research, as of 2026-10-15

Scope: web research only (papers, model cards, repository pages). No models were downloaded or run. Every factual claim carries a URL. "unverified" means the item could not be checked in the sources I could reach. Some pages returned 401/403/404 (AudioSR and Resemble-Enhance weight pages on Hugging Face, the NVIDIA AFX repo path, an Opus branch page), so those points are marked unverified.

Numbers are as published by the papers or pages cited. Where the publishing team is also the model author, that is noted. No independent benchmark was run.

Honest note for C. Live microphone input is usually already 48 kHz. Bandwidth extension only helps when the source is band-limited before it reaches the server: Bluetooth hands-free (narrowband/wideband), cheap USB mics with low-pass filtering, or narrowband telephony. Full-band mic input gains nothing and should bypass the model. The only candidate with a verified commercial-compatible licence and a documented causal, low-latency design is BBWENet. Its CPU cost has to be measured on the server; the figure of ~70 MMAC per second is the only published cost. The per-stream budget (~0.11 core for the noise model) can be compared only after that measurement. Nothing in the literature I found published a CPU-per-stream number for a causal BWE model at 48 kHz.

## 3. Excluded models and why

- **FLowHigh**: the paper is CC BY-NC-ND 4.0 and the code licence is not stated. Excluded for all three products. Source: https://arxiv.org/html/2501.04926v1 and https://jjunak-yun.github.io/FLowHigh.
- **UniverSR**: no licence stated for code or weights. Excluded. Source: https://github.com/woongzip1/UniverSR (page read, no licence).
- **BAE-Net / BAE-Net-lite**: no licence found; the repo's README says code "released soon" while the file list shows code. Excluded for B and C until licence is confirmed in writing. Source: https://github.com/yuguochencuc/BAE-Net.
- **Vocos-based BWE (arXiv 2603.07285)**: good objective numbers and a fast CPU RTF, but no code URL and no licence stated. Excluded. Source: https://arxiv.org/html/2603.07285v1.
- **AnyBand (arXiv 2608.00572)**: no code, no licence. Excluded. Source: https://arxiv.org/html/2608.00572.
- **BBWEXNet (Gómez et al., EUSIPCO 2023)**: real-time CPU design, 16 ms maximum algorithmic delay, but no code or licence was found. Excluded. Source: https://acris.aalto.fi/ws/portalfiles/portal/129462038/LOW_COMPLEXITY_REAL_TIME_NEURAL_NETWORK_FOR_BLIND_BANDWIDTH_EXTENSION_OF_WIDEBAND_SPEECH.pdf.
- **Salhab & Harmanani GAN (arXiv 2407.18571)**: no metrics on the page, no code, paper-only CC BY 4.0. Excluded. Source: https://arxiv.org/abs/2407.18571.
- **UBGAN (arXiv 2505.16404)**: 8 -> 16 kHz only, no code, no numbers on the abstract page. Excluded. Source: https://arxiv.org/abs/2505.16404.
- **NVIDIA Maxine Audio Super Resolution**: needs an RTX GPU on the Windows SDK path; the Linux SDK is for datacentre use; proprietary SDK terms (not read, because the AFX repo path returned 404). Excluded for B and C (no CPU path), and for A (CPU-only). Sources: https://docs.nvidia.com/deeplearning/maxine/audio-effects-sdk/index.html, https://blogs.nvidia.com/blog/2022/03/22/maxine-reinvents-communication-ai/.
- **Apollo**: music restoration, CC BY-SA 4.0 (commercial allowed, but not on B's licence list and not a speech model). Excluded. Source: https://github.com/JusperLee/Apollo.
- **Google Lyra**: codec, not bandwidth extension. Excluded. Source: https://opensource.googleblog.com/2022/09/lyra-v2-a-better-faster-and-more-versatile-speech-codec.html.
- **NVSR**: quality numbers exist (AP-BWE paper's table) but the licence of the full implementation could not be found (only the evaluation repo). Excluded from B and C; unverified for A. Source: https://arxiv.org/abs/2203.14941.
- **AudioSR, Resemble Enhance, VoiceFixer, MossFormer2_SR_48K, FlashSR, mdctGAN** are kept as "unverified" candidates for A, not as picks, because of either missing numbers, unverified weight licences, or generative risk.
- **HiFi-GAN+ and BEHM-GAN**: not checked in this pass. Unverified.

## 4. Other notes

- **2025-2026 literature**: the survey of audio super-resolution (May 2026) lists method families only and gives no comparison numbers. Source: https://arxiv.org/abs/2605.16681. The 2026 entries I found (Vocos BWE, AnyBand) are both excluded for licence reasons.
- **Metric conflict**: the same AP-BWE table reports LSD values that differ from the FLowHigh and UniverSR tables because those papers use different target rates (44.1 kHz versus 48 kHz) and different LSD variants (LSD-HF). Do not rank models across papers by LSD alone.
- **Speed conflict for Sidon**: the arXiv v2 text and the soniqo page give about 500x real time on GPU (batch 8; RTF 0.00200 on H200). A search snippet cites 3390x on the Hugging Face samples page; that figure was not confirmed by fetching the page (unverified). No CPU figure exists in either source.
- **Subjective evidence**: AP-BWE and BBWENet report listening tests with their own authors' stimuli. Neither has an independent listening test in the sources reached.
- **Unverified items**: AudioSR weights licence; Sidon's CPU speed; AP-BWE parameter count and causality; BBWENet CPU cost; ClearerVoice SR model weights licence; Resemble Enhance numbers; VoiceFixer numbers.

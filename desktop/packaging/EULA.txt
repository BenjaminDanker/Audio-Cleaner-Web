What it does online
Audio Cleaner works offline: it does not upload your files and does not collect personal data. It goes online only
for two things:
- Models. Setup (or Settings, later) downloads the models for subtitles and rebuilding the voice,
  once, from the app's releases on GitHub.
- Updates. When it starts, it checks the app's releases on GitHub for a newer version and, if there is one, downloads it (on
  Windows it is installed when you close the app; on a Mac you are asked to open the installer). This is a normal web
  request: GitHub sees your IP address and the version of the app, and nothing else is sent. You can turn this
  off in Settings ("Check for updates when Audio Cleaner starts") and update by installing a new version yourself.

Open source components
Audio Cleaner contains third-party open source components, among them Qt (LGPL v3), FFmpeg (LGPL v2.1), DeepFilterNet
(MIT / Apache 2.0), DPDFNet (Apache 2.0), WebRTC (BSD) and others, and the models it downloads are OpenAI Whisper (MIT),
Sidon (MIT) and Meta's w2v-BERT 2.0 (MIT). Each is licensed under its own terms, listed in the About
window and in the "licenses" folder of the installation. Where those licences give you rights, for example to replace
the Qt or FFmpeg files with your own builds, they apply.
